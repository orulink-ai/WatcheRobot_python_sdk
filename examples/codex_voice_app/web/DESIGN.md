# Design

用户在白天办公室的桌边，一边与机器人说话一边快速确认它刚拍到的东西；浅色、低干扰界面适合这一场景。

## Visual Theme

Restrained：暖灰绿色的中性表面，深松绿仅用于主操作与正在聆听状态。无装饰动画、渐变或透明玻璃。

## Typography

Segoe UI / Microsoft YaHei / PingFang SC 系统字体。正文16px，辅助14px，标题28px。正文最大宽度72ch。

## Layout

主区是对话，右侧320px是任务和照片证据。顶部紧凑显示连接、麦克风、主操作和独立停止。权限与诊断使用原生details逐步展开。小于900px变成单列，对话优先，停止保留顶部。

## Components

assistant-ui提供消息与输入框语义。照片以figure表示，允许打开原图，元数据在caption。任务是紧凑时间线，不使用嵌套卡片。所有操作≥44px，禁用、焦点与失败可见。

## Tokens

使用OKLCH定义背景、表面、文字、边框、强调色及危险色。正常正文对比度目标至少4.5:1。状态同时含文字与颜色，移动端无横向滚动。
