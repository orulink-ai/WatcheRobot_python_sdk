# 初见工作室配套包

此入口用于配套 ZIP，不会自动替换桌面内置 Runtime。应用广场安装使用客户端锁定的 SDK；客户端尚未集成本地扩展时，不能仅靠 app.json 版本范围保证兼容。

解压配套包，安装 Python 3.10–3.12。Windows 使用 application/delivery/setup.ps1，macOS/Linux 使用同目录 setup.sh。以下参数完全相同：

1. verify：校验 bundle.json 中所有 SHA256。
2. install：创建包内独立 .venv，安装配套 SDK wheel 和锁定依赖，需要网络。
3. 可选 flash --port COM10（替换为实际串口）：仅适用相同硬件的 ESP32-S3 / 32MB / PTL/no-wake 机型。关闭串口监控并保持供电。覆盖程序和内置资源，不全片擦除、不刷 STM32。刷前保留原固件备份，不要对不确定的机型尝试。
4. run：通过 SDK Daemon 启动 Application，不建立第二条业务连接。已有桌面 Daemon 时先核对版本，退出其他应用再启动。

--bundle 可显式指定解压目录。退出码 0 成功，1 校验/安装/运行错误，2 参数错误。校验值保证内容一致性，不代表签名认证。Windows 是当前验证平台，其他平台入口等价但尚未实机验收。

Codex CLI 需自行安装并登录。网页“声音与聆听”填写自己的火山 TTS/STT App ID、Access Token、资源和音色，再检测服务。目前没有阿里云适配器。新安装默认不自动开麦或启动。密钥保存在本机 settings.json，清除按钮删除当前配置；不要转发运行后产生的 artifacts 文件夹。

固件与 SDK 是本地配套构建，不等于官方发行版本，来源和哈希见 bundle.json。不包含作者的照片、密钥、配对记录或 Codex 登录。云端语音可用性由使用者资源授权决定。
