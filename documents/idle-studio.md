# 待机行为工作台使用说明

## 应用广场交付（0.1.0）

应用标识为 `com.orulink.idle_studio`，首版声明 Windows，依赖已发布 SDK `>=0.1.14,<0.2`。唯一编辑器源位于 `src/watcherobot/idle_studio`，发布目录携带该模块副本，不要求先发布新版 SDK。不要直接发布 application 模板子目录，因为它不含编辑器资源。

开发者在已安装当前源码的 Python 环境中执行以下跨平台 Python 命令，生成新的发布目录（目录已存在会拒绝覆盖）：

```console
python -c "from pathlib import Path; from watcherobot.idle_studio.marketplace import export_application; export_application(Path('dist/idle-studio-0.1.0'))"
watcherobot app check dist/idle-studio-0.1.0
```

将生成目录作为本地 Application 导入支持本地应用的 Watcher Desktop，安装其声明依赖后启动。ApplicationContext 由 Daemon 注入，不应直接双击 app.py。后台绑定随机本机端口并自动打开浏览器；如果浏览器未打开，从应用日志中打开 `Watcher Idle Studio` 后的地址。停止或切换应用后后台退出。独立运行调试仍可使用原模块入口。

正式上架另行执行 SDK 的 `app publish` 源码快照发布及 `app submit` 审核流程；这两步会写入外部平台，本次只准备可检查的目录和远端开发分支，没有执行公开发布或审核提交。依赖锁与发布快照由 SDK 发布流程生成。

配套固件分支为 `Ro-In-AI/WatcheRobot-Firmware:codex/idle-studio-firmware-20261117`，基于 f51b3b4b 的 AI Chat/JoyInside 版本，提供 `joy_idle_v1`、`joy_idle_pools_v1`、`idle_catalog_v1`。需 SD 已挂载且运行 AI Chat；PhoneControl 槽不保证提供此维护接口。普通主分支旧固件不能凭网页升级获得配置能力。

固件使用 ESP-IDF 6.0.2，按仓库构建指引构建 `firmware/s3/projects/ai-chat`；宿主测试依赖该项目已安装的 managed_components 中 cJSON。交付验证编译的是 AIChat 应用，不是全槽整机安装包。源码提交与二进制烧录是两个步骤，刷写必须匹配机器分区及目标槽。设备 DIY 配置保留；本次没有将 92/8 推广为官方默认。

发布资源包含客户端来源的 Watcher 模型及 Three.js 许可文件，归属见 vendor/README.md；官方表情 v0.0.10 首次在线下载，不将用户 SD、自定义配置或 JoyInside 凭据打入应用包。

通过本机运行的 idle_studio 服务打开工作台，USB连接Watcher，选择对应端口并读取设备。页面展示该机器的行为与SD素材，不用演示数据替代设备数据。

## 编辑与保存
- 概率输入1–100整数，按所在分组计算。其他行为自动分配剩余比例，各有效组总计100%。100%会暂停同组其他行为；0%显示为暂停，可输入正整数重新启用。整数分配可能使很小的行为暂停，请保存前检查。
- 旧配置读取时保留原值，因此可能显示小数。编辑概率或增删/移组后，相关组转为整数百分比。搜索不会改变计算分母。
- 添加默认10%，单行为组100%；删除行为保留素材。表情、动作、声音可分别替换，动作/声音可以选“无”。
- 修改先保留在网页草稿，点击保存到Watcher后才写入并回读校验。撤销恢复上次读取或保存结果。刷新/关闭页面前请保存。
- 若保存失败，草稿保留。若提示配置版本冲突，请重新读取后再编辑，避免覆盖其他窗口的修改。
- 日常待机与趣味表现来自设备的分组。schema3先按分组百分比抽池，再按组内比例抽行为；避免同组连续重复会影响下一次的实际概率。兼容schema2历史轮换配置，支持的设备默认开启分组概率草稿，保存后才升级设备配置。

## 素材
圆屏预览按需读取，表格浏览不下载动画。素材库支持导入，导入成功会直接存入设备；需要再选择到行为中并保存组合。支持GIF/PNG/JPEG/WebP，文件不超过2MB，动画最多120帧。读取/写入过程中保持USB连接。

## 本轮交付检查边界
已验证百分比实机保存回读、中文素材搜索、增加与撤销草稿，以及前后端回归。物理断电恢复、另一台机器切换、长时间待机/唤醒和导入后的实机播放未在本轮重新验收；这些不能由网页回归结果替代。

## 恢复官方默认
底部“恢复官方默认”按当前支持的 JoyInside 分组基线（joyinside-integration-on-dev-20261103）与机器现有素材重建默认草稿，恢复行为、分组、配套动作/声音和组内等概率。规则与该基线 joy_idle_defaults.c 一致；不是把上次保存配置当成默认。缺失的官方动画不加入，可选动作/声音缺失则为无；用户导入文件保留。未来固件默认规则变化时需同步此映射，不将其视为通用的固件默认查询接口。
确认后检查表格，再点击“保存到 Watcher”写入；保存前“撤销修改”回到上次读取/保存配置。未连接、演示、旧版不分组设备和通信过程中不可恢复。默认12项趣味组保持等概率，显示约8.33%，手动输入仍为1–100整数。

## 官方动画三维预览

三维预览默认展开。每行“预览此行为”播放当前组合的表情、动作与声音；“播放全部行为”按完整草稿随机连播，不受表格搜索或分组筛选限制。schema3按分组比例独立抽池，schema2按历史规则轮换；各组排除上次行为（仅一项时允许重复），跳过0%行为。每项等待动画、动作和声音的最长时长后切换。“停止”可取消加载及单项/连续播放。播放使用当前草稿，无需保存；编辑中的改动在后续抽取时使用。声音由电脑播放，首次点击播放启用音频。

复用客户端模型及转轴，按官方动作关键帧驱动；这是视觉模拟，不能替代实机舵机运动、初始姿态过渡及扬声器效果验收。拖动旋转，滚轮缩放。预览不会控制机器或写入配置。

动画来源为官方仓库 https://github.com/orulink-ai/WatcheRobot_sd/releases/tag/v0.0.10 的公开SD发布包，首次通过HTTPS下载并校验SHA256，无需GitHub账号或CLI，后续使用用户缓存目录。USB只负责设备目录和配置，预览不读取SD动画。版本固定，避免官方更新时静默改变预览。

优先按设备目录的动画SHA256匹配；没有摘要时使用精确ID和明确旧名称别名，并标注“按名称匹配，未校验设备内容”。自定义资源或已知内容不匹配会说明不可预览，不自动下载设备动画。

### 连续预览的素材准备

加载期间也可点击停止；停止立即移除加载及错误提示，已取消请求返回后不会重新播放或覆盖新的预览。演示模式仅体验表格编辑，不提供示例资源的真实三维播放。
播放全部行为时，当前行为播放期间提前准备下一行为的动画、动作及已解码声音；切换时整体启用三轨并保留画面直到下一段就绪。已解码组合采用96MiB预算缓存，当前和下一段的使用中引用另计。草稿变化后重新选择，停止后晚到结果不会恢复播放。首次资源同步或准备超时仍可能等待；组合持续时间保留三轨中最长时长，不截断音效或动作。
