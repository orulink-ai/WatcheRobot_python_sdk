## 背景、目标与边界

用户要求使用 ElevenLabs UI 组件改善已完成实机验收的局域网原声对讲应用。将通话设为主任务，现场照片为次任务；明确连接、静音、收听和拍照等待状态。保留已有 RTC、presence、释放与照片身份隔离。只复用既有麦克风流，视觉组件不取得媒体所有权，不新增设备通道。

验收：官方组件本地打包、不依赖 CDN；静音不显示伪造波形；取消后的迟到流不进入视觉层；断开设备仍有明确引导；响应式与减少动态效果可用；相关回归和浏览器检查通过。布局样式不适用先失败的单元测试，以实际浏览器验证；涉及媒体生命周期的回调先写测试。

## 方案与来源

沿用原生 DOM 控制器，在声音球体和音频波形处挂载 React 视觉组件，避免迁移稳定业务层。官方来源 https://github.com/elevenlabs/ui ，固定版本 23c31bd3088814215a8b5d0bfb56b327cad1a578（MIT）。文档站返回 403/429，改读官方仓库的 MDX 与 registry，不绕过网站验证。球体纹理改为本地生成，音量使用 manual 模式，波形不使用 demo 模式。

### 2026-10-12｜KID / Codex｜音频演示与中英文切换

用户收敛为全双工 RTC 对讲演示，默认关闭拍照并取消 camera.capture 必选要求。界面居中为单列，保留顶部机器人连接入口和双向声音控制；应用描述与 README 同步更新。可选开发拍照路径仍由服务端显式开关控制，默认拍照与照片下载接口均为 404。

用户追加海外使用需求。新增独立 i18n 展示模块，按浏览器首个支持语言选择中/英文，用户选择保存在本机；存储不可用时仍可切换。静态文字、动态通话/配对状态、错误、标题、无障碍名称和输入提示均切换。翻译不会改变 Application/RTC 通道或获取新的媒体流。

先写语言优先级、保存偏好、嵌套错误、参数化文本、存储不可用与非法语言测试；首次失败是模块未创建的接口脚手架，非语义 Red。实现后 3 项通过；相关 Node 对讲 / 语言 / 配对 / 降噪共 60 项通过，Python 服务 / 示例 / RTC 合同 102 项通过。发行文件检查确认 i18n 与连接器会随应用打包（这一检查为事后补测）。

真实浏览器确认英文选择刷新后保留，静态文字和设备信息切换正常。配对弹窗在英文下显示完整指导，输入有效长度连接码与非法 IPv4 后由后端拒绝，显示英文验证错误，未发起设备配对。真实通话中切换中→英→中，running 状态、静音和通话 request_id 保持，随后 user 原因主动结束。该短时验证仅证明切换无生命周期副作用，不证明新固件长期稳定。完成后恢复机器人连接、中文和默认视口。
