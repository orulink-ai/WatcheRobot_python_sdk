# Orulink 团队配置（按需采用）

仅在用户明确要求或目标项目已有这些约定时合并。通用开发档案规范不强制其他团队采用本配置。

- 每次 commit 使用规范、详细的中文描述，说明目的、关键变更及验证结果。
- 编写代码遵循 TDD、项目编程规范和职责解耦，不适用时记录原因与替代验证。
- GitHub 操作使用 gh 和本机已登录账号，不切换身份或嵌入令牌。
- PR 合入使用 `gh pr merge --merge` 或本地 `git merge --no-ff`；合入后检查最终合入 commit 是否有两个 parent，不使用 squash/rebase 合入。
- 不自动授予提交、推送或合入权限，不包含强制调用子 agent 的要求。
