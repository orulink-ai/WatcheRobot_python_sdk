# Pi 按语义先回应再操作

- 创建时间：2026-10-18 10:30:36 Asia/Shanghai；作者：Mr-KID-github；实施：Codex/root、contextual_voice_gate。
- 状态：本地完成并验证，已部署本机正式Application；未提交、未推送。
- 用户纠正：回复要结合原话，“打开小红书”先说“好的，我帮你打开小红书”；普通聊天直接自然回答，不能固定收到确认。规则放在Pi提示词中。

## 方案与边界
提示词负责语义和措辞；Pi扩展提供voice_reply工具，等待Application实际播放后完成，所有其他工具在本轮先回应完成之前阻止执行。聊天不需要此工具，最终回答仍等agent_settled。取消/播放失败不能放行，按轮隔离，并保护并行调用。
Application收到内部RPC语音请求后经现有Device channel播报；不修改Daemon、不另起意图分类模型会话（操作前语音需要一次工具往返）、不用规则猜测聊天/操作意图、不改变底层模型、手机MCP、固件、ASR及PCM协议。先回应不宣称已执行成功。

## 验收
- 操作的回应由Pi根据内容生成，实际播放完成→工具执行。
- 聊天仅一个自然回答，没有固定确认和额外TTS。
- 暂停、播放失败、不匹配交互请求、跨轮晚到与并行工具不能绕过门禁。
- 原分段预取、嘴型动作与资源关闭回归，真实Pi/机器人验证并恢复正式应用。
