# SD 读卡器官方资源安装与排障

桌面端通过 SDK Daemon 的维护接口安装官方资源。安装器源码位于
`src/watcherobot/runtime/daemon/maintenance/card_reader.py`，桌面端不维护另一份写卡实现。

## 安装顺序

1. 校验资源包格式、文件集合、各文件和整包 SHA-256。
2. 在目标卷创建独占的临时检查目录，验证小文件写入、长文件名原子重命名和读回。
3. 检查空间，按官方资源清单清理旧官方数据并写入新资源。
4. 写后重新验证 SHA-256，切换官方目录，全部成功后才显示完成。

预检失败时不会进入旧官方资源清理。预检通过只代表当时的小文件检查成功，不能保证整次传输或存储介质健康。安装中再次遇到 I/O 错误会停止，不会自动重试、格式化或执行磁盘修复。

预检成功后会删除本次独占临时检查目录。预检失败会保留该目录并停止继续触碰异常卷，以免清理错误覆盖最初的 I/O 错误；它不位于用户作品目录中。介质恢复后可处理这些以 `.watcher-write-check-` 开头的检查目录。

`watche/works` 是用户作品目录，官方安装不清理它。中断重试会使用安装事务恢复官方目录，不能把一次未完成的安装当作已激活版本。

## 常见错误

| 现象 | 含义与处理 |
|---|---|
| 资源包校验失败 | 安装包不完整或合同不匹配；重新下载并检查来源，尚未进入写卡 |
| 写入／重命名／读回失败 | 先停止安装，安全移除并检查 SD 卡、USB 读卡器和连接；备份数据后检查磁盘 |
| Windows 错误 1117 | Windows 报告底层 I/O 设备错误；不能仅根据文件名判断是资源包或软件路径错误 |
| `Errno 22` 指向 `.json.part` | 这是安装器的临时文件路径；需要结合原始 Windows 错误和磁盘检查结果排查，不应通过删除用户数据或关闭校验绕过 |
| 空间不足 | 安装器报告所需空间；释放不需要的数据或更换卡，不自动删除用户作品 |

磁盘检查报告损坏时，不要反复写入或尝试换短文件名继续。先备份重要数据，再由用户处理磁盘修复或更换卡／读卡器；恢复稳定读写后重新安装并完成最终校验。

本次真实设备调查证实写入链路返回 I/O 错误，并出现无效分配单元；尚不能区分 SD 卡、读卡器、接触或连接故障。软件预检和错误提示改进不等于介质已修复，也不等于整卡安装已验收。
